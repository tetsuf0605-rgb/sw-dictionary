# スター・ウォーズ辞典アプリ — Claude Code 指示キット

このフォルダは「アプリを作る前に、Claude Code への指示を整えておく」ためのキットです。
中身をそのままプロジェクトフォルダのルートに置けば、Claude Code が `CLAUDE.md` を自動で読み、
`docs/` の仕様に沿って段階的に実装を進められます。

```
sw-dictionary/                ← プロジェクトフォルダ（名前は自由）
├─ CLAUDE.md                  ← Claude Code が毎セッション自動で読むルール
├─ README.md                  ← このファイル
├─ docs/
│  ├─ 01_requirements.md      ← 要件定義（何を作るか、受け入れシナリオ）
│  ├─ 02_data_model.md        ← データ設計とネタバレ制御ルール（心臓部）
│  ├─ 03_ui_design.md         ← 画面設計・ナビゲーション・デザイン・アイコン仕様
│  ├─ 04_dev_plan.md          ← 開発フェーズと、各フェーズで Claude Code に貼るプロンプト
│  ├─ 05_content_guide.md     ← データ（作品パック）の書き方・新作追加手順・権利面
│  └─ PROGRESS.md             ← 進捗メモ（Claude Code が更新）
└─ data/
   ├─ meta.json               ← データのバージョン
   ├─ works.json              ← 全作品マスタ（2026年10月時点、2027年1月の『アソーカ』S2 まで）
   ├─ eras.json               ← 年表の時代区分
   ├─ CHANGELOG.md            ← データ更新履歴（アプリ内に表示）
   └─ packs/
      ├─ ep4/entities.json    ← サンプル：エピソード4 の項目（17件）
      └─ ep5/entities.json    ← サンプル：エピソード5 の追記（同一人物リンクの例）
```

## 使い方

1. **プロジェクトフォルダを作る**
   OneDrive の外（例：`C:\dev\sw-dictionary`）を推奨します。`node_modules` が OneDrive と同期すると
   非常に遅くなり、エラーの原因にもなります。
2. このキットの中身をそのフォルダにコピーする。
3. VS Code でフォルダを開き、ターミナルで `claude` を起動する。
4. 最初のプロンプトはこれだけで OK：

   ```
   CLAUDE.md と docs/ をすべて読んで、プロジェクトの理解を 10 行以内で要約してください。
   そのあと docs/04_dev_plan.md の Phase 0 に進みます。まず計画を示してください。
   ```

5. あとは `docs/04_dev_plan.md` のフェーズ順に、書いてあるプロンプトを貼って進めます。
   各フェーズに「完了条件」と「スマホで確認すること」があります。

## このキットで決めてある前提（変えたい場合は docs を直してから始める）

| 項目 | 前提 | 変える場合 |
|---|---|---|
| アプリの形 | PWA（ホーム画面に追加する Web アプリ）。iPhone / Android 両対応、ストア不要 | ストア配布したくなったら後から Capacitor で包める。データ設計は変えずに済む |
| 公開先 | GitHub Pages（既存アプリと同じ） | Vercel / Cloudflare Pages でも可 |
| 利用者 | 本人と家族。URL を知っていれば誰でも使えるが、ログインなし | — |
| 視聴の最小単位 | 映画 = 1 作品、ドラマ・アニメ = 1 シーズン | 02 の「作品の粒度」参照 |
| 言語 | 日本語 UI、日本語データ（公式日本語表記）、検索用に英語名も持つ | — |
| 画像 | 一切扱わない（権利面と容量の両方の理由） | — |
| データの書き手 | Claude Code に下書きを作らせ、あなたが確認する | 05 参照 |
| 収録範囲 | works.json には正史（カノン）の映画・ドラマ・アニメ全作品＋『ビジョンズ』を登録。実際の項目データは「パック」を作った作品から順に増える | 不要な作品は works.json から削るだけ |

## あなたが用意するもの

- **アプリ名**（仮称「ホロクロン」。作中用語なので、家族以外に配る場合は独自名を検討）
- **アイコン画像**：512×512 PNG を 2 種類（通常＋マスク対応）と 180×180（iPhone 用）。詳細は `docs/03_ui_design.md` の「アイコン仕様」
- **GitHub リポジトリ**（空でよい。名前は `sw-dictionary` を想定。変える場合は Phase 0 で Claude Code に伝える）
- **自分が視聴済みの作品リスト**（最初にパックを作る順番を決めるため）

## サンプルデータについて

`data/packs/ep4` と `ep5` は、設計の意図を Claude Code に伝えるための見本です。
内容は短く・自分の言葉で書いてあり、特に次の点を見せるためにあります。

- 「ベン・ケノービ」のような **同じ作品内の別名**（`names` の `revealedBy`）
- 「ダース・ベイダー」と「アナキン・スカイウォーカー」のような **作品をまたぐ正体の判明**（`sameAs`）
- 既存の項目に **後のパックから記述を追記** するやり方（ep5 のルーク、ベイダーなど）
- 年表に載る **出来事（type: event）** の書き方

本格的なデータ投入は Phase 8 で、`docs/05_content_guide.md` の手順に従って作品ごとに行います。
